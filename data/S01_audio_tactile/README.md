# Audio-Tactile Sample Subset

This subset contains 135 trials from participant S01 across 27 target emotion categories, with five repetitions per category.

Raw audio, tactile input messages, and audio/tactile features are included. Facial images and visual features were removed during release preparation. Original timestamps are retained. Visual removal does not indicate visual absence during acquisition. Raw audio is retained, so this subset is not claimed to be fully anonymous.

For access to the complete dataset, please contact Chaoqi Sheng at shengchaoqi@zju.edu.cn and describe your affiliation and intended research use. Access is subject to participant consent and applicable data-use conditions.

See the repository README for file descriptions and release_report.json for export verification.
